# KV Portofolio

A ready-to-publish static portfolio website for Kisan Kumar.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `kv_portofolio`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for the Pages deployment to complete.

Expected site URL: https://23F3003555.github.io/kv_portofolio/

This is a static HTML/CSS site. It does not require Python, Django, dependencies, or a build command.
